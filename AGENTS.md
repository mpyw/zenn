# Repository instructions

This repository contains Zenn articles. Before writing or substantially editing an article, read the [writing style guide](design/writing-style.md). Match the existing article's topic and technical level while following that guide.

Use the full-width comma `，` and full-width period `。` in Japanese prose. Put half-width spaces around Latin letters and numbers. Keep claims and code examples technically accurate, and preserve the intended front matter. Agent-specific usage or cost footers are not part of article content or the shared writing rules.
